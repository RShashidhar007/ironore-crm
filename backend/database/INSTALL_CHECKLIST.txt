VERIFICATION QUERIES:
================================================================================

Check all Products:
  SELECT PID, ProductName, ProductCategory, PStatus 
  FROM [dbo].[Product_Master]
  ORDER BY PID;

Check Inventory Status:
  SELECT 
    im.PID,
    pm.ProductName,
    SUM(CASE WHEN im.Category = 'Produced' THEN im.QuantityMT ELSE 0 END) as TotalProduced,
    SUM(CASE WHEN im.Category = 'Sold' THEN im.QuantityMT ELSE 0 END) as TotalSold,
    SUM(CASE WHEN im.Category = 'Produced' THEN im.QuantityMT ELSE -im.QuantityMT END) as Available
  FROM [dbo].[Inventory_Master] im
  LEFT JOIN [dbo].[Product_Master] pm ON im.PID = pm.PID
  GROUP BY im.PID, pm.ProductName;

Check Quotations Generated:
  SELECT TOP 20 QuotationNumber, ProductName, QuantityMT, PricePerMT, Status, CreatedDate
  FROM [dbo].[Quotations_Master]
  ORDER BY CreatedDate DESC;

Check Complaints:
  SELECT TOP 20 ComplaintID, CategoryType, Status, CreatedDate
  FROM [dbo].[Complaints_Master]
  ORDER BY CreatedDate DESC;

TROUBLESHOOTING:
================================================================================

Issue: Database connection fails
Solution:
  1. Check SQL Server is running
  2. Verify credentials in backend/.env
  3. Test connection: sqlcmd -S [server] -U [user] -P [password]

Issue: Quotation generation fails
Solution:
  1. Verify create_quotations_table.sql was executed
  2. Check backend logs for errors
  3. Verify MSSQL connection string

Issue: Inventory shows 0 available
Solution:
  1. Execute seed_inventory_data.sql
  2. Query: SELECT * FROM Inventory_Master;
  3. Verify Produced > Sold for products

Issue: Ollama connection error
Solution:
  1. Start Ollama: ollama serve
  2. Pull model: ollama pull llama2
  3. Verify: curl http://localhost:11434/api/tags

NOTES:
================================================================================

1. Database tables required:
   - Login_Master (authentication)
   - Customer_Detail (customer info)
   - Product_Master (product catalog)
   - Product_Category_Master (product types)
   - Inventory_Master (stock tracking) - POPULATED BY seed_inventory_data.sql
   - Complaints_Master (complaint tracking)
   - Quotations_Master - CREATED BY create_quotations_table.sql

2. Pricing model:
   - InitialPrice: Base cost per MT
   - SellingPrice: Sales price per MT
   - Available = Produced - Sold (in MT)

3. Available Stock Calculation:
   - Products with Produced - Sold > 0 are available for quotation
   - Orders/Quotations are generated against available inventory

4. Frontend features:
   - Chat button always visible (bottom-right)
   - Quick actions: Quotation, Order, Product Info, Complaint, Contact
   - Voice input (Chrome/Edge/Safari)
   - Real-time LLM responses
